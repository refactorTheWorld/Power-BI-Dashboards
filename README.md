**CAREER CONSULTANT DASHBOARD - DATA ANALYSIS BOOT CAMP PROJECT**

This dashboard was created for job seekers, Job transitioners and Job Swappers to solve a common problem. Information about the Job market is scattered and or incomplete and or hard to grasp. Its a project i did during an online data analysis  bootcamp provided by Luke Barousse.

- It displays information about a specific job you choose. That is it gives a user the following information:
    - Number of Jobs Posted 
    - Middle Annual Salary
    - Middle Hourly Salary
    - Highest paying data jobs
    - How each data and software engineering related job is trending in terms of demand.
    - The percentage of jobs for a particular type of job that allow you to work from home, list degrees as a requirement and or provide health insurance.
    - The location of said jobs.
    - Which platform we found that job on the most.

- It also allows you to filter by job schedule i.e. full time, part time, contract, so that you can get more valuable info when targeting jobs. e.g. if you used this filter you would know the percentage of these jobs that allow you to work remotely, list degrees as a requirement and offer health insurance. Thus you can adjust your strategy for that.

**Skills Utilised When Making This Dashboard**

- **Data Transformation (ETL) With Power Query :** I had to clean, shape and prepare the raw data for analysis by handling blanks, changing data types and creating new columns using power query.

- **Implicit Measures:** I had to formulate measures to derive key insights and KPIs like Median Annual Salary and Job Count.

- **Chart Visualisations :** Used column, bar, line and area charts to compare job counts and track trends over time. Also leveraged map charts to visualize the global distribution of jobs.

- **KPI Indicators and Tables :** Utilised cards to display information deemed as key and tables to provide granular sortable data.

- **Interactive Reporting :** Used slicers, buttons, book-marks and the drill through function to dynamically filter the whole report across sheets by job title, create a seamless navigation experience and enable users to navigae from a high level summary about a specific job to a view that provides more detailed specific information respectively.
